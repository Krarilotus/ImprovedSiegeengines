# Improved Siegeengines

نحوهٔ نبرد منجنیق‌ها، تریبوشت‌ها، برج‌های محاصره و سپرهای هوش مصنوعی را بهبود می‌دهد. برج‌های محاصره می‌توانند به دیوارهای بیشتری بچسبند و نیرو حمل کنند: پیاده‌نظام را انتخاب کرده و برای سوار شدن روی برج محاصرهٔ خودی کلیک کنید. مهندسان روغن می‌توانند آتش را روی زمین باز بگسترانند.
