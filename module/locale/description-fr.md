# Improved Siegeengines

Améliore le combat des catapultes, trébuchets, tours de siège et boucliers de l’IA. Les tours de siège peuvent accoster plus de murs et transporter des troupes : sélectionnez des fantassins et cliquez sur une tour alliée pour embarquer. Les ingénieurs d’huile peuvent propager le feu sur terrain dégagé.
